# Workshop shop: a React client with Apollo Client 4

A React 19 page that lists the orders of the [shop server](../shop-server/README.md), with Apollo Client 4 and Vite. It replaces the old React 17 + apollo-boost client, which is kept for comparison in [`legacy/apollo-example/packages/client`](../../legacy/apollo-example/packages/client).

`src/OrderList.tsx` works, but: one hand-written query for the whole page, a hand-written type that nothing checks against the schema, and neither a loading nor an error state.

## Setup

```sh
npm install
npm test

# in a second terminal: the server on port 4000
cd ../shop-server && npm install && npm run start:solution   # Apollo Server 5 on Express 5

npm start            # http://localhost:5173, /graphql is proxied to port 4000
```

## Exercise 1: GraphQL Codegen

1. `@graphql-codegen/cli` and `@graphql-codegen/client-preset` are already in `devDependencies`. Write `codegen.ts` (`codegen.solution.ts` shows the shape): schema `../shop-server/src/schema.graphql`, documents `src/**/*.tsx`, output `src/gql/` with `preset: 'client'`.
2. Run `npm run codegen` and replace `gql` plus the hand-written `OrdersData` with `graphql()` from `./gql`. Hover over `data`: where does the type come from now – and what type does `status` have?
3. Rename a field in the query to something the schema does not have. What does `npm run typecheck` say? Add `npm run codegen` to CI, so generated files never drift.

## Exercise 2: Fragments per component

1. Split the row into its own component `OrderRow` with `fragment OrderRow on Order { id totalCents ...StatusBadge }` and a `StatusBadge` with `fragment StatusBadge on Order { status }`. Read the data with `useFragment`.
2. Compose the fragments in one page query – one request, no waterfall of queries per component.
3. Render a loading state, an error state and an empty state, and test all three with `MockedProvider`.

## Solution

`solution/` contains a possible solution for both exercises (`solution/gql/` is generated by `npm run codegen:solution` from `codegen.solution.ts`): `npm run start:solution`.
